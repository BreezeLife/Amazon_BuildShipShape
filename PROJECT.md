# DayTrace

DayTrace is a wearable-first personal memory and productivity companion for the Amazon Developer Hackathon Bee track. It transforms Bee-derived context into a readable daily timeline, a concise reflection, and a small next-step cue for Rokid Glasses.

The project must distinguish simulated development data from real Bee data. The final submission may only claim Bee-track compliance once the application is connected through an official Bee CLI, MCP, or Agent Skill path.
